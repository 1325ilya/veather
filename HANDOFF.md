## 4. CI
- `.github/workflows/build.yml`, runner `macos-26`. Каждый новый push **отменяет** предыдущий прогон (`cancel-in-progress`), поэтому «cancelled» ≠ ошибка. Не пушить, пока нужен результат предыдущего.
- Дымовая проверка прогона: скрипт `/tmp/ciwait.sh <sha7>` (копия в `App/Tools/ciwait.sh`) — цикл: раз в минуту `curl https://api.github.com/repos/1325ilya/BetterThanBox/actions/runs?per_page=10`, найти run с `head_sha` на нужный хэш, выйти когда `status == completed` и вывести `conclusion`. Запускать в фоне (`run_in_background`, timeout до 1 800 000 мс). Ошибки: `mcp__github__get_job_logs` (failed_only, return_content).
- Релиз `nightly-dev`: `https://github.com/1325ilya/BetterThanBox/releases/download/nightly-dev/BetterThanBox.ipa` (неподписанный; в теле «Build N (sha)»). Приложение умеет самообновляться оттуда (Настройки → Проверить обновления, `BTBSelfUpdate`).
- Последний коммит `2684711`: кеш DerivedData (`actions/cache`, ключ `deriveddata-v1-<hash pbxproj>`) + `COMPILER_INDEX_STORE_ENABLE=NO DEBUG_INFORMATION_FORMAT=dwarf`. Первый прогон с кешем заполняет его; сравнить время второго. Владелец просил «собиралось быстрее».
- Типичные ошибки: в ObjC не использовать блоки внутри `switch case` без скобок; `vm_region_basic_info_64` не имеет `share_mode`; линковка CoreGraphics (`-framework CoreGraphics`); в Swift тернарник с `.localized(...)` писать как `String.localized(...)`.

## 7. Важные факты о подписи
- Сертификат владельца имеет **профиль на один bundle id** `app.potato6941.pomegranate3375` (не wildcard). Любое приложение, подписанное им, получает этот id и **ставится поверх BetterThanBox**. Другой id iOS не установит («Unable to Install»). Нужен второй профиль/App ID или wildcard. Владельцу это объяснено (дважды).
- Поэтому проверить игру рядом с BetterThanBox на этом сертификате нельзя: игра заменяет BetterThanBox (данные пропадают, нужен бэкап «Настройки → Резервная копия»).
- BetterThanBox можно обновить без Devin: Настройки → Проверить обновления → подписать своим сертификатом → установить (тот же id → обновление поверх, данные целы). Об этом владельцу написано.
- Предпроверка в экране подписи предупреждает «Профиль не wildcard» (так и должно быть).
