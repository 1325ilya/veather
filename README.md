# BetterThanBox

On-device iOS IPA-подписчик и менеджер приложений — «лучшее из всех» (аналог GBox / KSign / ESign / Feather). Основа — [Feather](https://github.com/khcrysalis/Feather) (GPL-3.0), код приложения в `App/`.

## Сборка

Собирается в GitHub Actions (`.github/workflows/build.yml`), готовый **неподписанный** IPA — в релизе [`nightly-dev`](https://github.com/1325ilya/BetterThanBox/releases/tag/nightly-dev). Подпишите его своим сертификатом (p12 + mobileprovision) в самом приложении.

## Что умеет

| Возможность | BetterThanBox |
|---|---|
| Подпись p12/mobileprovision, ad-hoc, «только изменить» | ✅ |
| Пресеты подписи, массовая подпись, предпроверка | ✅ |
| Клоны приложения (2–20) с номером на иконке | ✅ |
| Удаление расширений/Watch, снятие ограничений, fix иконок, thin arm64 | ✅ |
| Изоляция keychain, редактор/конструктор entitlements | ✅ |
| Экспорт `.ipa` / `.tipa` по шаблону имени | ✅ |
| Встроенные твики: No Ads, Network Blocker, No Rate, iPadUI, Bypass Updates, Sideload Fixes, Data Manager | ✅ |
| Твики из `.deb`/`.dylib`, Tweak Vault, ElleKit вместо Substrate | ✅ |
| Поиск по всем источникам, авто-выбор самой новой версии, закрепление источника | ✅ |
| Обновления библиотеки по всем источникам, пропуск версии | ✅ |
| «Здоровье источников», встроенный браузер для IPA, конструктор AltStore-репозиториев | ✅ |
| Установка: локальный сервер + itms-services, IDevice (VPN+pairing) | ✅ |
| Хранилище с защищённым набором, файловый менеджер (plist/text/hex) | ✅ |
| Логи, история действий, «Здоровье сертификатов» (OCSP) | ✅ |
| Резервная копия сертификатов/источников/настроек с паролем | ✅ |
| Блокировка Face ID, фоновые проверки + уведомления, самообновление | ✅ |
| Shortcuts, браузер IPSW, инфо об устройстве | ✅ |
| Полная русская локализация | ✅ |

Сознательно **не** реализовано: обход отзыва сертификатов, подбор паролей p12, каталоги краденых/enterprise-сертификатов, обход внутренних покупок/подписок, скачивание платных приложений без покупки и пиратские репозитории.

## Исходники аналогов

Для анализа в `repos/` лежат сабмодули других проектов. Клонировать с ними:

```
git clone --recurse-submodules --shallow-submodules https://github.com/1325ilya/BetterThanBox
```

ESign, GBox, Scarlet и Sideloadly — закрытые, их исходников нет.
