# BetterThanBox

Коллекция open-source iOS-подписчиков и сайдлоадеров (аналоги GBox / KSign / ESign) в виде git-сабмодулей в `repos/`.

Клонировать со всеми сабмодулями:

```
git clone --recurse-submodules --shallow-submodules https://github.com/1325ilya/BetterThanBox
```

ESign, GBox, Scarlet и Sideloadly — закрытые приложения, их исходников нет.
